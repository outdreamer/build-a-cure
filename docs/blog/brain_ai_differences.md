# Brain/AI differences

It's useful to identify relevant differences between an 'AI trained on my thoughts (or otherwise using my thoughts as a prompt or base network)' and the 'actual brain that generates those thoughts'.


## Brain/AI comparison

Brain variables vs. AI variables include:
- a brain has 'previous usages of itself stored in structures like neuron connection strength' (which is different from an AI that just 'connects or applies my set of rules, or applies my set of rules as high priority'. This is not a trivial difference, it's similar to the important difference between 'identifying and storing a set of rules in a database' and 'applying those rules' and 'applying those rules optimally')
- a brain has 'flexibility' built-in, allowing functions like 'generate new neurons as "new requirements for variation" are identified' (an AI model needs to implement this using an algorithm to constantly update itself, which most AI models don't apply/implement, and when they do apply/implement it, it's not an optimal update algorithm)
- a brain has 'relevance components like "reusability/importance" built-in to functions like "prioritize"' (so that recent/important/frequently used info is automatically protected/applied as a constant/optimized for recall/reusage)
- a brain has 'self-analysis functionality' built-in, a function which can be 'run on any sufficiently large set of available neurons, evaluating any other sufficiently small set' (which most AI models do not already implement optimally, which in order to implement, the AI models would need to 'regularly/optimally apply optimization algorithms to subsets/connections/sub-graphs/graph layers/structures of neurons')
- a brain has 'definition storage that can be updated to reflect new understanding/insights' like 'updating the definition/graph of relevance/optimality, when new variation/graphs identifies a new optimization structure' (most AI models apply definitions statically instead of constantly updating/optimizing their definitions)
- a brain has 'consciousness functionality' built-in, like 'activating subsets of the brain or the complete brain as required' (most AI models have 'a static set of possible neuron activation patterns')

In these cases, the brain is consistently more capable of 'optimization of relevant variation' compared to most AI models.
