# Alternates to quantum structures

It's useful to identify what else can act like a 'quantum process', other than the quantum processes themselves.

The following can 'act like a quantum process' by implementing functions like 'coordination/organization/connection':
- existing common structures (specifically, existing common causal structures, like 'molecular forces which create other connections')
- equivalent alternates (structures that 'act similar to each other, without communication')
- prediction functions like 'empathy/understanding' to identify common predictor variables like 'incentives' (a good prediction function can 'predict the probable actions of another agent and coordinate with those predicted probable actions')
- caring (caring generates a 'prioritized connection to other structures')
- understanding (understanding 'activates the brain to import connections of structures')
- thinking (thinking about other structures generates 'connections to other structures')
- expecting (expecting a structure can generate 'connections to that structure')

These can all 'generate connection structures' similar to how quantum processes can 'generate connection structures'.

Is it possible to implement a function like 'change this physical structure by thinking about it'? 

As a follow-up to the discussion in 'mind_physics_applications.md':
- a huge number of neurons are required to solve most complex problems, and 'changing a physical structure by thinking about it' is a complex problem
- in order to 'change a physical structure by thinking about it', a set of intents needs to be implemented in the correct sequence (identify the sequence of changes to the structure, hold the sequence in your mind while implementing it or regularly switch back to the sequence after implementing each change in the sequence, identify the solution state of the structure after the changes are applied, make room for new variation and make new variation adjacent while holding the existing state in your mind, identify possible structures that could invalidate it, identify whether the intents to invalidate it are stronger than other intents, identify whether it increases relevant variation which is a universal intent, etc)
- it's possible to simplify some problems, like rather than importing an entire structure into 'a set of active/conscious/connected neurons', importing its 'limits/defining variables' can sometimes be useful as an alternative, and some problems can be simplified to identifying a 'simple/single causal change, that can create the original solution changes'
- an abundance of 'free/available neurons' is required to identify useful structures like 'alternate solutions', 'paths to solutions', 'more optimal solutions', 'analyze solutions', etc to make the changes 'permanent/real/relevant'
- 'specific structures of neurons' may be required for 'consciousness' (like 'neurons connected by adjacently stored neurons' or 'neurons with common connections' or 'neurons with a prior coordination connection')

If the above requirements are fulfilled (the number of neurons, the ratio of available neurons to used neurons, the specific type of neuron connections, etc), 'changing a physical structure by thinking' is possible.
