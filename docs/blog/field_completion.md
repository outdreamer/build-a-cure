# Field Completion

It's useful to describe 'graphs to complete a field'.


## Definitions

Graphs to complete a field:
- cover all the relevant variation (all the interactions, interfaces, variables, optimizations, etc) of the field
- optimally describe/explain the field or its inputs/other equivalent alternates (like 'trivializing the field by identifying its most important general variables/concepts or its optimal variable interaction graphs')


## Examples

Comedy is very incomplete and not well-defined, but can be more completed by structures including:
- the definition of irrelevance ('invalidities/contradictions/obvious/trivial/simple/irrelevant errors' are 'wrong', so they are funny)
	- similarly, relevance can be applied as an opposing variable ('connecting everything to frequently irrelevant variables like sex/disgust' is a 'simple source of errors/comedy')
	- relatedly, 'surprisingly wrong' errors are 'maximally different' errors which involves independence (a component of relevance)
- the other structures of comedy include:
	- simple similarities (as in 'callbacks', which are a simple similarity/relevance structure)
	- otherwise irrelevant/invalid/incorrect similarities
	- interfaces like 'importance/intent/stupidity'
- optimal structures of comedy include:
	- optimal similarities (maximally different similarities across graphs of interfaces)

Biology has more identified relevant graphs than comedy, such as:
- bio-system general variable interaction graphs (like interactions of general variables like 'stress/inflammation/signaling/repair')
- bio-system causal specific structures (like gene/pathway) interaction graphs (like 'specific/general causal pathway interactions')
- bio-system importance/relevance graphs (like graphs of variables with 'varying relevance/importance')

Physics/math have even more identified relevant graphs, such as:
- graphs of 'topics/sub-fields of math'
- graphs of 'math structure like number type interactions'
- graphs of 'optimality of physics rule variants'

Other graphs which can completely describe the fields include:
- cross-system interaction graphs (physics/math interactions, physics/biology interactions, chemistry/biology interactions)
- system optimization graphs (identifying optimal bio-system states and possible/valid connections between these states)


## Interface graphs

To complete the field of 'interface analysis', as described elsewhere, the following graph variables are required:
- a complete set of graphs 'describing all relevant "interface variable" variation'
- a set of graphs to implement optimal intents like 'constantly optimize the set of relevant graphs for relevant variation (like a high solution/problem ratio)'
- a set of graphs to 'graph the set of relevant graphs' (implementing 'graphs of relevant graphs')
