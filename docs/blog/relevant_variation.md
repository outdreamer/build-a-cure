## Definition

What is relevant variation?

So 'relevant variation' can involve:
- 'usable/analyze-able complexity' (like a 'level of complexity' that is useful or usable by current functionality)
- 'relevant problems' (like 'problems which have solutions that can solve other/subsequent problems')
- 'optimal variables' (like 'variables which cause optimal variation' like 'maximally independent variables like interfaces')
- 'relevant new graphs/algorithms' (like 'maximally different, maximally optimal new graphs/algorithms/structures')
