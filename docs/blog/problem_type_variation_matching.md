# Problem Type Variation Matching

It's useful to describe 'low/medium/high complexity/variation' problem types and the 'structures sufficiently similar in complexity/variation to be able to optimize/solve them'.


## Low complexity problems

Low-complexity problems like 'optimizing a well-defined structure for a well-defined metric' can likely be solved with 'trivial applications of identified optimizations', like 'applying an identified trivial set/sequence of optimizations, to a trivial graph (like a system graph)'.


## Medium complexity problems

Medium-complexity problems like 'solving physics' can likely be solved with 'non-trivial applications of identified optimizations', like 'relevant graphs of optimizations'.


## High complexity problems

High-complexity problems like 'identifying the optimal graph of relevant variation (reality)' can likely be solved with 'non-trivial applications of unidentified optimizations', like by solving the problem-solving intent of 'optimizing graphs' and 'organization/implementation', which, once solved, will likely identify 'optimal applications/implementations of graphs' which are required to solve high complexity problems.
