# Alien Minds

Alien minds can be defined as 'independent minds'.


## Definition

An 'independent mind' can be defined as:
- a mind that is so much more advanced than other minds that it 'doesnt require/use the potential/power/functionality of other minds'
- a mind that 'requires extremely independent intents'
- a mind that 'otherwise differs on interface variables to an extreme degree/structure (as in sufficiently extreme as to generate/cause independence)'
- a mind that can sense/identify extremely independent variables (like 'having a much better understanding of physics' or 'having much better senses, like being able to sense gravity/light in different optimal ways')
- a mind that is 'similarly capable in potential, but has a more optimal starting point' (like 'starting from a point where more optimal intelligence was required/evolved, bc more complex problems were encountered and solved previously in their ancestry') or is otherwise 'similar but different on interface variables'


## Examples

Alien minds could be implemented like:
- a 'maximally different mind' like a 'mind that tests differently than identified species test', like a 'mind where each neuron is a different sense'
- a 'mind that is different in intent' like 'optimizing physics' or 'distributing physics optimally', which differs from identified species intents like 'simply simulate physics rules using simple identified structures'


## Identifiers

Alien minds could be identified like by:
- identifying the 'most different sequence of problems identifiable' that could cause the 'most differences in minds'
- identifying the 'most optimal minds possible and their identifiers' like the 'minds with the most possible freedom/potential' like 'minds implementing the most optimal possible variants of physics rules'
