# Suboptimalities in mind structures

Existing 'default mind structures' are very suboptimal as a result of 'efficiencies/solutions/optimizations applied to solve previous problems'.


## Examples of suboptimalities

Existing suboptimal mind structures:
- a 'simple structural similarity' memory function
- a 'local neuron coordination' optimization function (to identify 'local optimizations of adjacent neurons')
- a 'temporary cross-neuron general similarity/coordination/connection' mind-wave function
- a 'temporary blood flow' activation function
- a 'single (weighted/constant) neuron connection function' that prioritizes a single suboptimal thinking type like 'bouncing around simple variation within a boundary network' (which assumes the 'boundary network is correctly/relevantly defined' and assumes 'simple variation' is 'sufficient to solve the problems possible within those boundaries')
- a 'neuron connection function requiring specific neuron surface structures'
- a 'single (general or specific) difference from optimal' function to identify errors

These suboptimal structures result from 'solving the previous problems suboptimally':
- solving the problem of 'storing useful info' in a simple way (like 'prioritizing storing only the most recent identified info' as opposed to 'implementing optimization structures, like prioritizing different combinations of the most important components of relevance')
- 'depending on previous identified solutions' like 'memory (like instinct as in inherited memory)', applied to solve problems like 'filtering simple structures'
- 'allocating/prioritizing attention' to 'solve one problem at a time' ('focus' as in 'lack of multi-tasking'), as opposed to 'identifying/storing commonly useful/otherwise relevant structures to solve the maximum of intents'


## Possible optimalities

What is optimal about the mind includes that it is possible to:
- 'solve some optimization problems using the above suboptimal structures', optimization problems whose 'solutions enable other optimization intents, if applied iteratively'
- 'change variables/functions/structures' like 'change neuron-connection function types' and 'change similarity-identification functions' and 'change thinking types applied to the mind'
- it is possible to 'increase neuron count' by 'learning/thinking'

However, implementing these optimizations takes 'a lot of thinking time, and optimal thinking priorities/intents/structures like "maximized thinking effort", and continual application of optimal thinking' for a normal brain, as indicated in generating_biological_intelligence.md.

What would be more optimal is a mind like the following:
- a mind with 'stored memories of useful structures (like the definition of relevance, a definition/template of an optimal mind that can be copied iteratively, etc)'
- a mind that can 'self-optimize' by applying those 'useful structures', like by 'trivially/relevantly switching/changing its neuron positions/structures to organize its neurons for optimal connections/queries/interactions'
- a mind that can generate/filter/optimize interactions of other minds, like by 'storing a mind description in each neuron, and expanding/implementing/applying each mind with layers of surrounding neurons' and 'identifying optimal problems for minds to solve by requiring mind conflicts'
