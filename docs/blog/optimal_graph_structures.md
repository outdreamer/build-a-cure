# Optimal graph structures


It's useful to identify 'optimal structures on a graph', by applying 'optimalities of difference (like what is optimally different)'. This is related to relevant_graph_intents.md.

What should be structured as 'different' on a graph:
- independent variables should be different, until theyre connected optimally, like by identifying all the optimal interactions of those independent variables'
- problems should be different from solutions ('connections to solutions' as in 'causes of solutions' should be trivial on a directed/causal graph, 'causes of problems' should be non-trivial on a directed/causal graph)
- problem optimizations/variation/complexity should be different from solution optimizations/variation/complexity

What should be 'similarly different':
- problems should be non-trivial to cause, across all relevant graphs, except specific graphs like a 'causal problem type graph (where problems can be identified as causing other problems trivially, in a way that is useful)'

What should be 'different' across graphs:
- identify what is the 'optimal graph format of concept definition graphs' (like specific structures indicating the 'different relevance of each concept', like structures 'specifying a concept graph so its causal impact on another graph is trivially identified', or structures indicating that a 'relevance graph is higher priority than another graph')
