# Equivalent problems


It's useful to identify 'similar/related/equivalent problems' to identify the 'most optimal variant of the problem to solve', like:
- the 'most well-defined variant' (like the 'variant with the highest info ratio', or the 'most quantized variant', or the 'most specific variant', or the 'graph/structure variant', etc)
- the 'most adjacently/trivially/optimally solvable variant'


## Examples

Equivalent problems include:
- solving the problem of 'optimizing graphs' solves the problem of 'equivalence/connection'
- solving the problem of 'identifying relevant graphs and their optimal connections, iterated to a degree where all variation in graph intents is trivially/relevantly connected' solves the problem of 'optimizing graphs'
- solving the problem of 'relevance' solves the problem of 'optimality'
- solving the problem of 'definition/structure' solves the problem of 'implementation'
- solving the problem of 'identifying similar relevance' solves the problem of 'identifying new relevance'


## Related intents

'Identifying equivalent problems' enables other intents like:
- 'identifying problems which will overlap at some point on some graph (bc of the similarity of those problems), thereby enabling identify the conflict resolution of the intersection of those problems'
- 'identifying maximally different problems' which is useful to identify 'graphs that solve for multiple intents'
- 'identifying problems which solve other problems' (like how solving 'low-information high-complexity problems' can solve 'other problem types')
- 'identify graphs of problem types that trivially/optimally connect maximally different problem types (to identify variables like problems causing other problems and problem types that solve other problem types and problem types that can optimize other problem types on some metric)'

'Identifying equivalent problems' can be optimally implemented by:
- 'solving the graph optimization problem' (since 'graphs are a core connection/similarity structure' which can solve other problems of 'connection/equivalence', like 'identifying equivalent problems')
